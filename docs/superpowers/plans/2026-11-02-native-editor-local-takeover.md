# Native editor local takeover while an Android upload is pending

> Use disjoint Terra author agents. Root alone owns Git, builds, tests and runtime.

Goal: prove that revoking the remote editor through the real Pi terminal keeps
the worker alive, fences its old Android upload and permits later explicit work.

## Qualification prerequisite

The existing private Native claim observer omitted the optional `{ paged: true }`
argument. Correct and behavior-test that observer before extending its evidence.
An input trace alone does not prove forwarding: the real registry behind the
observer must refuse paged claims without a paged-capable reader and distinguish
paged and unpaged grants/proofs. Requalify the actual Native same-session workflow

but cannot prove paged-specific lease coverage. Empty-prefill expansion normally
uses an unpaged Source lease even when the later upload is large; it must not be
misclassified as a paged-claim test.

## Real action and scope

Ctrl-] (`\x1d`) in the owned Native worker is the supported local-takeover key.
The Source synchronously invalidates its remote upload and closes the published
remote question, releases/forgets the actual lease and opens the original local
editor. The process, session, runtime, peer and original SDK invocation remain
alive. This does not preserve the same published remote question or grant.

The local editor's result is initially pending; do not invent a cancellation or
SDK result. A later explicit Escape may cancel locally, and must be recorded as
that local action, not a phone Cancel or a replay of the old submitted value.
